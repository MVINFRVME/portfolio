Аналитика для бизнеса — с нуля, агентной разработкой

LitEnergy / управляющая компания

Задача

02

Чат-боты заказов и мониторинга: СНГ и Middle East

Золотое Яблоко

Задача

Нужны были рабочие Telegram-боты под разные регионы: экспресс-заказы и заказы по самовывозу в России, Казахстане и Беларуси, а также мониторинг потока заказов в Middle East (ОАЭ, Саудовская Аравия, Катар).

03

CLI-агент с tool calling

Проект подготовки к техническим собеседованиям

Задача

Не обёртка над чатом, а агент, который сам выбирает действие: взять вопрос, оценить ответ, показать прогресс.

Что сделал

Классический agent loop: Ollama + tool calling (get_question, grade_answer, get_progress). Банк ~230 вопросов, оценка по rubric, свой оркестратор на Python.

Эффект

Подготовка к техническим собеседованиям стала системной: вопросы по темам, оценка ответов и прогресс в одном цикле — без хаотичного поиска и «просто поболтать с чатом».

agent loop tool calling Ollama Python
04

RAG по PDF: от файла к ответу с источником

Навигация и точечный ответ по правилам настольных игр

Задача

Внешние ИИ-сервисы часто путают или не знают правила настольных игр. Нужен поиск по документам с ответом по источнику, а не «по памяти» модели.

Что сделал

RAG на Python: парсинг PDF (PyMuPDF), embeddings (sentence-transformers), ChromaDB, hybrid search, генерация через Groq. Интерфейс — Telegram-бот (aiogram). Старт на Ollama, из-за долгих ответов ушёл на Groq.

Эффект

Рабочий пилот «документ → поиск → ответ по источнику». Тот же каркас подходит под внутреннюю базу знаний и разбор документов в компании.

RAG Python PyMuPDF ChromaDB hybrid search Groq aiogram
